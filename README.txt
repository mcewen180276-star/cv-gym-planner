CARDIO STUDIO V3 — INSTALLATION

Upload ALL SIX FILES from this ZIP directly into the ROOT of your existing GitHub Pages repository (not into a folder). Replace the old versions.

Open your published app, refresh the page, then go to Class builder. At the very top you will find Number of participants, Total class length, Warm-up, Cool-down, and Briefing. Under those is Smart automatic layout.

IMPORTANT: If the old version remains, close the installed app, open the GitHub Pages site in Chrome, refresh and reopen. The service worker is upgraded to network-first to prevent future stale versions.

Your data is stored locally in the browser under the same GitHub Pages site origin. Back up from Settings before changing sites or clearing browser storage.
